func CheckRenameInvariance(t testing.TB, p program.Diagnoser, c CorpusCase)
    CheckRenameInvariance requires a diagnosis to survive a consistent rename of
    the recorded application's resources, labels, images, and ports. Namespace
    names, IPs, digest-pinned images, binary ConfigMap data, and HTTP paths stay
    fixed because the corpus cannot safely substitute their external targets.

func ExternalNameEndpointViolations(detector sdk.Detector, serviceNames []string) []string
    ExternalNameEndpointViolations checks that a detector never reports an
    ExternalName Service because it lacks ready endpoints or backing pods.

    For each Service name it compares two snapshots that differ only in the
    Service's backends: the realistic one, where the ExternalName Service has no
    Endpoints, EndpointSlices, or pods, and a counterfactual one that supplies
    ready backends. A finding about the Service that appears only in the
    realistic snapshot can only come from an endpoint or pod readiness check,
    which Kubernetes never satisfies for a DNS alias. Findings that do not
    depend on backends, such as a Service type check, are allowed. Pass the
    application's own Service names so inventory-scoped detectors are exercised.

func HealthyBaselineViolations(detector sdk.Detector, snapshots []Snapshot) []string
    HealthyBaselineViolations replays the detector on recorded snapshots of the
    healthy application and returns actionable messages for active findings
    and unavailable observations, using the production observation checks.
    The snapshots are healthy by construction, so any active finding is a
    false positive that would open an incident before any fault exists.
    An error cannot prove quietness and is also a violation. Resolved findings
    are ignored.

func ProjectCapturedObject(raw []byte) ([]byte, error)
    ProjectCapturedObject preserves arbitrary Kubernetes fields, including
    object identity (metadata.uid), while stripping credential payloads,
    last-applied copies and volatile write metadata. Discovery callers exclude
    Secrets entirely; this also protects recorded JSON.

func ScriptOrigin(script program.RunScript, c CorpusCase) (program.ScriptOriginReceipt, error)

    It never matches opaque shell commands against typed external effects.

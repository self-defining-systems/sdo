package appstate // import "sdo.dev/operator/sdk/appstate"

Package appstate lets a health-class detector package expose state the
application itself defines (an admin setting, a database setting, process
state) as typed key-value pairs. A reader is Go code that implements Reader;
the controller runs it on its own interval, off the detection path, and carries
the last finished result in the observation. Detectors and playbooks read that
result through Require and its predicates.

A reader gets the narrow View, not program.ReadView: no command execution,
no authenticated HTTP, no writes. Every read refuses credentials. Prototype:
no secret filtering on Values; readers must not select secret columns.

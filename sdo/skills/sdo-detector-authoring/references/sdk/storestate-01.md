package storestate // import "sdo.dev/operator/sdk/storestate"

Package storestate reads value-free facts about a data store: whether it accepts
writes and why not, its replication role, its connection and memory caps,
its principals and their grants, its catalog (indexes, validators, locks) and
inventory counts. It never reads records.

An engine Adapter supplies one read command, run inside the store's own
container through the podread path with the store's own CLI, and the parser
of its output. Facts from a healthy moment form a baseline; Diff lists the
items that differ now, so a finding names the exact setting, role or grant that
changed. A read that gives no answer is an error, never a healthy result.

    refused when health was promoted is never observed, so its later refusals
    stay coverage gaps instead of being compared with a refused reference.
    It returns nil for a pod read that is not a store-state read.

type Adapter interface {
	Engine() Engine
	DefaultPort() int
	ReadCommand(Endpoint) []string
	// Parse returns the facts of a complete read. A read that reached no
	// server, or lacks a section, is an error.

    Adapter is one engine's read: an argv run in the store's container (its own
    CLI, credentials from the container environment, output never carrying a
    secret or a record) and the parser of its output. The read is one command so
    a store costs one pod read.

func AdapterFor(engine Engine) (Adapter, bool)
    AdapterFor returns the engine's adapter, or false when SDO has no reader for
    the engine yet.

type Change struct {

    Before is nil for an added item and After is nil for a removed one.

type Config struct {
	// Spec is the detector's spec; a v1 Pod watch is added when absent.
	Spec sdk.DetectorSpec
	// Component is the application-map component the store belongs to.
	Component string
	// Engine selects the adapter; it must have one (AdapterFor).
	Engine Engine
	// Target selects the store's Pods and container by role.
	Target podread.Target
	// Port is where the store listens in its container; 0 is the engine default.
	Port int
	// ReadInterval is the pod-read interval; 0 is podread.MinInterval.
	ReadInterval time.Duration
	// Baselines are facts from a healthy moment, one per store Pod name, or a
	// single baseline every Pod is compared with. Without them the detector
	// compares with the controller's promoted healthy readings of its pod
	// read (podread.Result.Baseline), and without those only absolute facts
	// are judged: write blocks, refusals and near-cap use.
	Baselines []Facts
	// GapWithoutBaseline makes a store Pod the detector has no healthy
	// baseline for a coverage gap instead of a finding or an error: a read
	// that is unavailable, unparsable or refused clears, and
	// ConfirmationReason says why the store is not observed. Go sets it on
	// the readers it installs from the application map, which no designer
	// checked against the store's image or credentials, so a store SDO cannot
	// read never stalls deployment acceptance or an incident's recovery. Once
	// the Pod was read healthy, the same reads are a refusal finding or a
	// detector error as usual. Absolute facts of a readable store (write
	// blocks, near-cap use) are judged either way.
	GapWithoutBaseline bool
}
    Config declares one store component to watch.

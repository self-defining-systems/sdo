package podread // import "sdo.dev/operator/sdk/podread"

Package podread exposes bounded command output from inside running containers to
deterministic detectors. A detector declares the command and which Pods hold the
role; the runtime runs it on the declared interval and freezes the output into
the snapshot. No exec occurs in detectors.

CONSTANTS

const (
	MaxQueries       = 8
	MaxTargets       = 16
	MaxArgs          = 32
	MaxArgBytes      = 1024
	MaxIDBytes       = 128
	LimitBytes       = 4 * 1024
	MaxConcurrent    = 4
	MinInterval      = 30 * time.Second
	ExecTimeout      = 3 * time.Second
	CollectionBudget = 5 * time.Second
)
    Limits bound declarations, target fan-out and retained output, so a read
    can neither load the application nor stall the controller's evaluation loop.
    MaxConcurrent and CollectionBudget apply across every query of a cycle.

type Reading struct {
	Namespace  string    `json:"namespace"`

    Reading is one container's output. A nonzero ExitCode is a result the

type Target struct {
	Labels map[string]string `json:"labels,omitempty"`
	Image  string            `json:"image,omitempty"`
}
    Target selects Pods by role from observed objects in the application
    namespace, never by name. Every label must match, and Image (an RE2 over
    the container image) selects the container. Without Image the Pod's first
    container is read. Pods that are terminating or finished are not targets.

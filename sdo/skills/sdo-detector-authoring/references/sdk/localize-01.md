package localize // import "sdo.dev/operator/sdk/localize"

Package localize ranks the application components that can explain the active
synthetic-traffic failures, so incident detectors and playbook programs bind
and gate a repair on the faulty component instead of on every Service a failing
journey touches.

It is deterministic and reads only observations the controller already provides:
the judged traffic window of one workload (scenario paths are the scenario's
target Service plus its DependsOn list) and, when a detector consumes it,
the Service reachability window.

A component scores 2 when it is on every failing scenario path, 1 more when it
is on no healthy evaluated scenario path, and 2 more when its own Service has
a sustained run of failed dials. Suspects are the components with the highest
score. Scores rank evidence; they never prove a cause: a program still checks
its own evidence on the bound component (an exec, a status, a source diff)
before it matches.

    Diagnose returns it (Unknown), never NoMatch: the evidence is unavailable.

package vantage // import "sdo.dev/operator/sdk/vantage"

Package vantage gives deterministic detectors typed, read-only probes made
from inside an application Pod: a fresh TCP or HTTP dial to a named peer from
the Pod's own network namespace, its traffic-control queueing disciplines,
its processes' limits and states, its container cgroup's CPU, memory and IO
limits and pressure, its /dev/shm usage and its socket table.

The kinds are a closed set and each runs a fixed command. The runtime runs them
in a helper container it attaches to the Pod (an ephemeral container of a pinned
minimal tools image that shares the target container's process namespace and the
Pod's network namespace), so a probe works whatever the application image holds.
A detector declares probes (Consumer); the runtime runs them on their interval
within a collection budget and freezes typed readings into the snapshot. No exec
occurs in detectors.

FUNCTIONS

func ClientLinks(result Result, link traffic.Link) []traffic.LinkObservations
    ClientLinks turns a dialing probe's readings into one client-vantage link
    series per Pod, for traffic.JudgeLinkIn. The healthy latency is the median
    of the successful baseline dials, so a slow client egress is judged against
    the client's own healthy dials, not the prober's. A Pod's link is qualified
    once one of its dials, or a baseline dial, succeeded.

func ClientSetting(probe Probe, pod string, observedAt time.Time) traffic.LinkSetting
    ClientSetting is how a probe's dials are judged: DialsPerProbe consecutive
    failures report a link, and the newest dial may be up to two intervals old.

func Command(probe Probe) ([]string, error)
    Command returns the fixed argument vector the helper runs for a probe.

func LongestInterval(d sdk.Detector) time.Duration
    LongestInterval is how stale a declared probe can be at evaluation.

func NewClientLinkDetector(spec sdk.DetectorSpec, id string, from podread.Target, link traffic.Link, interval time.Duration) (sdk.Detector, error)
    NewClientLinkDetector returns a detector that dials link from inside the
    Pods holding the from role (a TCP connect, or an HTTP GET when the link's
    protocol is http) and reports each Pod whose dials traffic.JudgeLinkIn
    finds unreachable, intermittent or slow, as a client-vantage link finding.
    When a link-probe workload dials the same edge, the finding records the
    prober's judgement: "prober_condition" is "healthy" when the prober sees the
    edge fine, which places the impairment on the client side ("impairment":
    "client-egress").

func NewClientLinksDetector(spec sdk.DetectorSpec, links []ClientLink, interval time.Duration) (sdk.Detector, error)
    NewClientLinksDetector is NewClientLinkDetector for several edges under
    one detector: each link is dialed from inside its own calling role's Pods,
    so a fault on the client's side of an edge (loss or a partition on the
    client's egress) is seen even when the prober reaches the callee.

func NewDetector(spec sdk.DetectorSpec, probes ...Probe) (sdk.Detector, error)
    NewDetector returns a detector that runs the given state probes and reports
    one finding per Pod and condition Judge finds, primary resource the Pod and
    related resource the probe's workload when it names one. A probe without
    any answer is a detector error, never a clear. Dialing probes are refused:
    judge them with NewClientLinkDetector.

func ValidateDetector(d sdk.Detector) error
    ValidateDetector validates a consumer at registration. Targets come from the
    snapshot's Pods, which only a Pod watch keeps observed.

func ValidateProbes(probes []Probe) error
    ValidateProbes rejects malformed, duplicate or excessive declarations.

type Judgement struct {
	Condition Condition
	Evidence  string
}
    Judgement is one condition a reading shows, with its evidence.

func Judge(reading, base Reading) []Judgement
    Judge reports the conditions a state reading shows, against base (the same
    probe's healthy baseline reading, zero when there is none). Dialing kinds
    are judged by the link rules (ClientLinks), not here. A reading with an
    error shows nothing.

func (d SourceDiff) ContainerChanges() ([]ContainerChange, error)
    ContainerChanges compares the pod template of a workload (or a Pod) with
    accepted source, container by container: an added init container is {Kind:
    InitContainer, Added: true}, never an image change of an app container.

func (d SourceDiff) Field(path string) (FieldValues, error)
    Field compares one dotted field path, such as "spec.replicas" or
    "spec.template.spec.nodeSelector", on both sides. Containers are matched by
    name with ContainerChanges, never by list position.

func (d SourceDiff) PresentButNotInSource() bool
    PresentButNotInSource is true while the object exists live but not in
    accepted source. Unlike SourceAbsent it turns false after the delete,
    so delete-style Diagnose matches on it.

func (d SourceDiff) Sides() (accepted, observed map[string]any, err error)
    Sides returns the accepted-source and live comparable fields. A nil side is
    an absent object.

type WatchKind struct {
	APIVersion string
	Kind       string
	Namespace  string
}

type WindowedDetector interface {
	EvaluationWindow(DetectionContext) time.Duration
}
    WindowedDetector is implemented by detectors that judge a rolling window of
    past observations, so a condition that has just resolved can keep reporting
    until the window rolls over. EvaluationWindow bounds that lag for the
    current view; zero means the detector has no such window.

Package servicehealth holds app-agnostic structural health checks that localize
synthetic-traffic failures: they say which Service stopped routing to which
workload, not only that a user path fails.

func NewReachabilityDetector(spec sdk.DetectorSpec) sdk.Detector
    NewReachabilityDetector reports every eligible Service that has a ready
    selected pod while the last Failures fresh TCP dials of one of its ports,
    all made after the Service gained that ready backend, failed. A prior
    successful dial is not required: a port that never accepted a connection
    while its pods report Ready is exactly the fault this detects. Without dial
    observations in the context it reports nothing. A controller-authorized
    healthy reference retains never-served declarations as observations instead.

func NewReadyEndpointsDetector(spec sdk.DetectorSpec) sdk.Detector
    NewReadyEndpointsDetector reports every Service with a selector that has
    no ready endpoint, unless every workload it selects is scaled to zero on
    purpose. ExternalName Services never have endpoints and are skipped.

func ReachabilityEligible(service corev1.Service) bool
    ReachabilityEligible reports whether a Service is dialed: it has a
    cluster IP that load-balances to selected pods. ExternalName Services
    are DNS aliases, headless Services resolve to pod IPs without targetPort
    translation, selector-less Services have hand-managed backends, and Services
    SDO creates for itself are not the application's.

func ReachabilityTargetConfiguration(ctx sdk.DetectionContext, target ReachabilityTarget) (string, bool)
    ReachabilityTargetConfiguration binds a target to its observed Service,
    selected backend configuration, referenced ConfigMaps and selecting network
    policy. Incarnation metadata and allocated routing addresses/ports are
    not application configuration. The probe uses Service DNS + service port,
    not NodePort or an allocated IP family. Headless versus virtual-IP routing
    remains significant. It never reads credentials or Secret resources.

func ReachabilityCatchingUp(ctx sdk.DetectionContext, w ReachabilityWindow) []ReachabilityTarget
    ReachabilityCatchingUp returns the targets whose Service gained its ready
    backend so recently that fewer than Failures dials follow the transition,
    none of them failed. Confirmed counts only dials made after the Service's
    readySince, so a repair that replaces the only ready pod leaves the window
    incomplete until that many dials follow; dialing these targets early fills
    it with the same proof. A failed dial ends the catch-up: failure runs keep
    the normal interval.

func ReachabilityTargets(ctx sdk.DetectionContext) ([]ReachabilityTarget, int)
    ReachabilityTargets derives the dial targets from a namespace snapshot:
    every TCP port of every eligible Service, sorted by Service and port,
    at most MaxReachabilityTargets. It also returns how many were omitted.

type Engine struct {
	// Has unexported fields.
}
    Engine runs one workload's scenarios. It alone decides which scenario an
    iteration runs, seeds its random source, bounds its time, and measures it.

func NewEngine(workload Workload, catalog Catalog, client Doer, baseURL func(Target) string, clock Clock) (*Engine, error)
    NewEngine validates workload against catalog and prepares its schedule.
    baseURL maps a scenario target to scheme://host:port.

func (e *Engine) Descriptors() []Descriptor
    Descriptors describe the workload's scenarios in workload order.

func (e *Engine) Iterate(ctx context.Context, iteration uint64) (string, Sample)
    Iterate runs iteration once and never returns an error: every failure is
    a sample. Cleanup steps of a write-with-cleanup scenario run after any
    request was sent, even when a step failed; their failures are reported in
    CleanupError and do not change the outcome.

func (e *Engine) Plan(ctx context.Context, iteration uint64) ([]Request, error)
    Plan builds, without sending, the requests of iteration assuming every step
    succeeds without saving state. It is meant for replay and review.

func (e *Engine) Rand(iteration uint64) *rand.Rand
    Rand is the random source of iteration: the same workload seed and iteration
    always yield the same values, so a failing probe replays exactly.

func (e *Engine) Run(ctx context.Context, first uint64, emit func(scenario string, sample Sample)) (uint64, int)
    Run starts iterations at the workload's arrival pattern and rate,
    from iteration first, until ctx ends or, for bounded workloads, the duration
    elapses. At most MaxInFlight iterations run at once; an arrival that finds
    them all busy is skipped. It waits for running iterations and returns the
    next iteration number and the number of skipped arrivals.

func (e *Engine) ScenarioAt(iteration uint64) Scenario
    ScenarioAt is the scenario iteration runs. The schedule is a smooth weighted
    round-robin cycle, so every scenario runs at its weight's share and the
    choice depends only on the iteration number.

func (e *Engine) Workload() Workload
    Workload returns the engine's workload with defaults applied.

type FaultClass string
    FaultClass is a failure a scenario must detect. Every scenario must detect
    FaultUnreachable and FaultErrorStatus; the others are declared when the
    scenario's checks are strong enough to catch them.

const (
	// FaultUnreachable: the target refuses connections or does not resolve.
	FaultUnreachable FaultClass = "unreachable"
	// FaultErrorStatus: the target answers with a 5xx status.
	FaultErrorStatus FaultClass = "error-status"
	// FaultWrongBody: the target answers 200 with an empty or wrong body.
	FaultWrongBody FaultClass = "wrong-body"
	// FaultSlow: the target does not answer within the request timeout.
	FaultSlow FaultClass = "slow"
)

func (e *HTTPEndpoint) WithJSON(template string, params Params) *HTTPEndpoint
    WithJSON adds a JSON body, for the many write APIs that take one. template
    is the JSON document; each {key} in it is replaced by the generated value of
    params[key] or, failing that, the State value an earlier step saved, escaped
    for a JSON string. Write "{key}" for a string and {key} for a number.
    The filled body must be valid JSON.

type Link struct {
	From     string           `json:"from"`
	To       string           `json:"to"`
	Port     int              `json:"port"`
	Protocol LinkProtocol     `json:"protocol,omitempty"`
	HTTP     *LinkHTTPOptions `json:"http,omitempty"`
	GRPC     *LinkGRPCOptions `json:"grpc,omitempty"`
}
    Link is one declared dependency edge: From calls To on Port.

func UndrivenLinks(catalog Catalog, workloads []Workload) []Link
    UndrivenLinks returns the edges declared by link-probe workloads that no
    scenario of a health-probe workload drives, sorted by ID. A scenario drives
    an edge when its Target or DependsOn names both ends. A link probe proves
    only that a fresh connection opens; a fault that answers the connection but
    fails the request (a broken payment call behind checkout) shows only through
    a continuously probed scenario whose request crosses the edge, so each edge
    returned here is one the health probes cannot see break.

func (l Link) EffectiveProtocol() LinkProtocol
    EffectiveProtocol preserves the TCP default for older observations.

func (l Link) ID() string
    ID names the edge.

func (l Link) String() string
    String renders the edge for humans.

type LinkObservations struct {
	Link    Link         `json:"link"`
	Samples []LinkSample `json:"samples"`
	// Qualified reports whether a dial of this link has ever succeeded. A
	// link that never did may simply not admit the prober, so it is not a
	// health signal; only a link that worked and stopped is.
	Qualified bool `json:"qualified"`
}
    LinkObservations are one link's recent samples, oldest first.

type Outcome string
    Outcome classifies one iteration of a scenario.

const (
	OutcomeOK      Outcome = "ok"
	OutcomeError   Outcome = "error"
	OutcomeTimeout Outcome = "timeout"
	// OutcomeInvalid marks a generator bug: a request could not be built or
	// broke a safety rule, so nothing was sent. It is not a health signal.
	OutcomeInvalid Outcome = "invalid"
)
type Param interface {
	Value(rng *rand.Rand, state State, generated map[string]string) (string, error)
}
    Param generates one request parameter from the iteration's random source,
    its shared State, and the parameters of the same request generated so far.

func Const(value string) Param
    Const is a fixed value.

func DateRange(from string, to string) Param
    DateRange picks a calendar date (YYYY-MM-DD) in [from, to].

func DaysAfter(param string, min int, max int) Param
    DaysAfter is a date between min and max days after another date parameter of
    the same request, such as a check-out date after a check-in date.

func FloatBetween(low float64, high float64, decimals int) Param
    FloatBetween picks a decimal in [low, high] rounded to decimals places.

func FromPrevious(key string) Param
    FromPrevious is a value an earlier step of the same iteration saved in
    State, for example with SaveJSON.

func FromSeed(count int, render func(index int) string) Param
    FromSeed picks one of the count records the application seeds at startup
    and renders it, for example a seeded user name. Use FromSeedPair when two
    parameters must describe the same record.

func IntBetween(low int, high int) Param
    IntBetween picks an integer in [low, high].

func OneOf(values ...string) Param
    OneOf picks one of values uniformly.

type Params map[string]Param
    Params maps parameter names to generators. Parameters are generated in
    sorted name order, except that parameters derived from another parameter of
    the same request (DaysAfter) come after the one they derive from.

func DefaultLatencyScenarios(workloads []Workload) []string
    DefaultLatencyScenarios returns, sorted, the scenarios of health-probe
    workloads whose effective SLO keeps DefaultMaxLatency. The default bound
    is generous so that any application starts green; a saturated service
    often slows its path many times over long before it fails, and a read that
    normally takes tens of milliseconds can stay under the default while its
    service is pinned at its CPU limit. Each scenario returned is a critical
    path whose slowdown health cannot see.

func FailingUserScenarios(ctx sdk.DetectionContext) []string
    FailingUserScenarios lists, as "workload/scenario" sorted, every qualified
    health-probe scenario of the context's carried windows that violates its SLO
    now: the user-facing failures a cause-only detector may gate on. It is empty
    when the context carries no traffic.

func FromSeedPair(key string, count int, first func(index int) string, second func(index int) string) (Param, Param)
    FromSeedPair returns two parameters rendered from the same seeded record,
    such as a user name and its password. The record index is kept in State
    under key, so later steps can reuse it with FromPrevious.

func KnownBrokenChanges(window Window) string
    KnownBrokenChanges describes the KnownBroken scenarios of window whose state
    changed from their declaration: one that now meets its SLO, or one whose
    recent failures include a status key outside FailsWith. It is empty when
    every KnownBroken scenario still fails as declared or has too few samples to
    judge. It is a note for the detection designer, never a finding.

func LinkFinding(spec sdk.DetectorSpec, namespace string, window Window, observed LinkObservations) (sdk.Finding, bool)
    LinkFinding explains one link JudgeLink reports, with per-link p50/p95
    latency and failure classes. The primary resource is the target Service;
    the calling Service is related.

func LinkFindingIn(spec sdk.DetectorSpec, namespace string, setting LinkSetting, observed LinkObservations) (sdk.Finding, bool)
    LinkFindingIn explains a link JudgeLinkIn reports. A client-vantage finding
    has its own rule ID (the prober's with a ".client" suffix) and names the
    client Pod, so it stands next to the prober's judgement of the same edge:
    slow from the client while fast from the prober places the impairment on the
    client's egress.

func NewDetector(spec sdk.DetectorSpec, workload string) sdk.Detector
    NewDetector returns a health detector that reports every qualified scenario
    of a health-probe workload that violates its SLO. It decides purely from
    the prober's observed samples; missing or unproven observations remain
    unconfirmed and cannot establish health. A health-class spec that leaves
    Persistence.MinDuration unset holds each violation until its failing samples
    span DefaultHealthMinDuration, so judge-authored and lifecycle-generated
    traffic-health detectors alike require a sustained failure, counted from the
    first failing sample, before they fire, not just an evaluation count.

func NewLinkDetector(spec sdk.DetectorSpec, workload string) sdk.Detector
    NewLinkDetector returns a health detector that reports every qualified link
    of a link-probe workload that JudgeLink finds unreachable, intermittent or
    slow. It decides purely from the prober's samples; with no observations it
    reports nothing. The sample counts are the hysteresis, so unlike NewDetector
    it does not add DefaultHealthMinDuration. Unreachable and intermittent links
    are critical; a slow link still serves, so it is a warning: batch warnings
    for slow links to open incidents.

func ScenarioFinding(spec sdk.DetectorSpec, namespace string, workload Workload, scenario Descriptor, verdict SLOVerdict) sdk.Finding
    ScenarioFinding explains one unhealthy scenario. The primary resource is
    the Service the scenario calls; the Services it depends on are related,
    so the finding localizes the fault along the request path.

type Endpoint interface {
	Build(ctx context.Context, rng *rand.Rand, state State) (Request, error)
	Check(response Response, state State) Verdict
}
    Endpoint builds one request and judges its response. Build must derive
    every varying value from rng and state; the engine seeds rng per iteration,
    so the same iteration always builds the same requests. Check may save values
    into state for later steps. Neither may measure time or send requests.

type Engine struct {
	// Has unexported fields.
}
    Engine runs one workload's scenarios. It alone decides which scenario an
    iteration runs, seeds its random source, bounds its time, and measures it.

func NewEngine(workload Workload, catalog Catalog, client Doer, baseURL func(Target) string, clock Clock) (*Engine, error)
    NewEngine validates workload against catalog and prepares its schedule.
    baseURL maps a scenario target to scheme://host:port.

func (e *Engine) Descriptors() []Descriptor
    Descriptors describe the workload's scenarios in workload order.

func (e *Engine) Iterate(ctx context.Context, iteration uint64) (_ string, result Sample)
    Iterate runs iteration once and never returns an error: every failure is a
    sample. A scenario's setup steps run first until each has succeeded once
    in this engine (or an engine it shares setup with); a retry resumes at the
    first step that has not succeeded. A failed setup step fails the sample, and
    setup time is not part of its latency. Cleanup steps of a write-with-cleanup
    scenario run after any request was sent, even when a step failed; their
    failures are reported in CleanupError and do not change the outcome.

func (e *Engine) IterationOf(scenario string, from uint64) (uint64, bool)
    IterationOf is the first iteration at or after from that runs scenario:
    the request the schedule would send for it, so running it now repeats a
    scheduled request. ok is false for a scenario the workload does not run.

func (e *Engine) Plan(ctx context.Context, iteration uint64) ([]Request, error)
    Plan builds, without sending, the requests of iteration assuming every step
    succeeds without saving state. It is meant for replay and review.

func (e *Engine) Rand(iteration uint64) *rand.Rand
    Rand is the random source of iteration: the same workload seed and iteration
    always yield the same values, so a failing probe replays exactly.

func (e *Engine) Rate() float64
    Rate is the iterations per second the engine starts: the workload's rate,
    raised when its scenarios' sampling floor needs more.

func (e *Engine) Run(ctx context.Context, first uint64, emit func(scenario string, sample Sample)) (uint64, int)
    Run starts iterations at the workload's arrival pattern and rate,
    from iteration first, until ctx ends or, for bounded workloads, the duration
    elapses. At most MaxInFlight iterations run at once; an arrival that finds
    them all busy is skipped. It waits for running iterations and returns the
    next iteration number and the number of skipped arrivals.

func (e *Engine) ScenarioAt(iteration uint64) Scenario
    ScenarioAt is the scenario iteration runs. The choice depends only on the
    iteration number: it follows the workload's SamplingPlan, which gives every
    scenario of a health probe its floor and shares the rest by weight.

func (e *Engine) ShareSetup(source *Engine)
    ShareSetup makes e use source's record of completed setup steps, so a setup
    step that succeeded in either engine is never run again by the other.
    A process that runs the same catalog in several engines (a continuous probe
    and its verify bursts) shares one record: data a setup step wrote and that
    was lost afterwards then fails every engine instead of being written again.
    Both engines must run the same catalog.

func (e *Engine) UseExec(execer Execer)
    UseExec lets scenarios run EXEC steps on ssh targets through execer.
    An engine without one records such steps as invalid.

func (e *Engine) UsePasswords(source Passwords)
    UsePasswords lets scenarios that declare Users sign in with the passwords
    source returns. A prober gives every engine the same source.

func (e *Engine) Workload() Workload
    Workload returns the engine's workload with defaults applied.

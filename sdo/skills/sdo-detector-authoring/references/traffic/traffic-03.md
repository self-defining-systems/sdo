func (e *HTTPEndpoint) OrExisting(status int, text string) *HTTPEndpoint
    OrExisting makes the step an ensure step: a response with status whose body
    contains text means the data the step creates already exists, and the step
    passes without its Contains and SaveJSON checks. Use it for setup steps that
    create a test identity or fixture, which must pass on a fresh application
    and on one that already has the data.

func (e *HTTPEndpoint) SaveCookie(name string, key string) *HTTPEndpoint
    SaveCookie stores the value of the response's Set-Cookie named name in State
    under key; a response without it fails. Use it on a login step of a test
    identity the scenario created, and send the session with WithHeader.

    SaveJSON stores the JSON field at dotted path (for example "id" or
    "data.id") of the response in State under key; a missing field fails.

func UndrivenLinks(catalog Catalog, workloads []Workload) []Link
    UndrivenLinks returns the edges declared by link-probe workloads that no
    scenario of a health-probe workload drives, sorted by ID. A scenario drives
    an edge when its Target or DependsOn names both ends. A link probe proves
    only that a fresh connection opens; a fault that answers the connection but
    fails the request (a broken payment call behind checkout) shows only through
    a continuously probed scenario whose request crosses the edge, so each edge
    returned here is one the health probes cannot see break.

func JudgeLink(window Window, observed LinkObservations) (LinkJudgement, bool)
    JudgeLink reports a qualified link whose fresh dials show it unreachable
    (LinkFailing), intermittent (at least LinkLossPercent of the last
    LinkLossWindow dials failed, consecutive or not) or slow. Slow needs each
    of the last LinkSlowWindows windows of Failures dials to have a median
    above the bound: LinkLatencyFactor times the baseline, the baseline plus
    LinkSpreadFactor times its spread, and MinLinkLatencyBound, where baseline
    and spread are first multiplied by the slowdown the link's peers (the
    setting's Peers) share. A loaded prober node slows every dial alike, so it
    never makes one link slow. A stalled host (HostStallBound) explains dial
    timeouts and slowness everywhere at once, even where the peers stay fast:
    slowness is not judged while any judged dial was made on a stalled host,
    its timeouts do not count toward intermittent, and a run of them is
    unreachable only once it fills LinkLossWindow dials. Refusals, resets and
    protocol failures are judged as usual. Only recent samples are judged:
    the slow and loss windows reach back at most the larger of MaxAge and twice
    their length in probe periods.

func JudgeLinkIn(setting LinkSetting, observed LinkObservations) (LinkJudgement, bool)
    JudgeLinkIn judges dials with an explicit setting, so the same rules judge a
    link-probe workload's dials and a vantage probe's dials from a client Pod.

type LinkObservations struct {
	Link    Link         `json:"link"`
	Samples []LinkSample `json:"samples"`
	// Qualified reports whether a dial of this link has ever succeeded. A
	// link that never did may simply not admit the prober, so it is not a
	// health signal; only a link that worked and stopped is.
	Qualified bool `json:"qualified"`
	// BaselineLatency is the median latency of the link's first
	// LinkBaselineSamples successful dials, recorded once by the prober. Zero
	// means no baseline yet, and latency is then not judged.
	BaselineLatency time.Duration `json:"baselineLatencyNs,omitempty"`
	// BaselineSpread is the median absolute deviation of those same dials
	// from BaselineLatency.
	BaselineSpread time.Duration `json:"baselineSpreadNs,omitempty"`
	// Vantage is where the dials were made from; empty means the prober.
	Vantage LinkVantage `json:"vantage,omitempty"`
	// ClientPod names the client Pod a client-vantage series was dialed from.
	ClientPod string `json:"clientPod,omitempty"`
}
    LinkObservations are one link's recent samples, oldest first.

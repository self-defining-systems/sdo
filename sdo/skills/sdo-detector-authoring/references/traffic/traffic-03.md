func MatchFailures(window Window, patterns ...logs.Pattern) ([]FailureMatch, error)
    MatchFailures returns the recent failing samples of window's qualified
    scenarios whose Error matches a pattern, scenario by scenario, oldest first,
    one match per sample and pattern. It sees the same recent samples Judge does
    (usable, within the SLO's age and window), so a cause-specific detector
    keys on the exact failure text instead of searching a finding's Evidence.
    Patterns are RE2 and use the same ID and size rules as log patterns;
    a malformed pattern is an error, never a non-match.

type FaultClass string
    FaultClass is a failure a scenario must detect. Every scenario must detect
    FaultUnreachable and FaultErrorStatus; the others are declared when the
    scenario's checks are strong enough to catch them.

const (
	// FaultUnreachable: the target refuses connections or does not resolve.
	FaultUnreachable FaultClass = "unreachable"
	// FaultErrorStatus: the target answers with a 5xx status, or an EXEC
	// exits non-zero.
	FaultErrorStatus FaultClass = "error-status"
	// FaultWrongBody: the target answers 200 with an empty or wrong body.
	FaultWrongBody FaultClass = "wrong-body"
	// FaultSlow: the target does not answer within the request timeout.
	FaultSlow FaultClass = "slow"
)

func (e *HTTPEndpoint) Each(path string, field string, pattern string) *HTTPEndpoint
    Each requires the JSON array at dotted path ("" for the whole body) to be
    non-empty and every member's value at field ("" for the element itself) to
    match the RE2 pattern, so one malformed or dangling member fails the step.

func (e *HTTPEndpoint) ExactSet(path string, field string, want ...string) *HTTPEndpoint
    ExactSet requires the JSON array at dotted path ("" for the whole body)
    to hold exactly the members want, in any order: none missing, none extra,
    no duplicates. field is the dotted path of each member's value inside an
    array element ("" when the elements are the values). Each {key} in want is
    filled from State. Use it when the probe owns the data, so the healthy set
    is known exactly.

func (e *HTTPEndpoint) JSONEquals(path string, want string) *HTTPEndpoint
    JSONEquals requires the JSON value at dotted path (object keys and array
    indexes, for example "data.items.0.id") to equal want exactly. Each {key} in
    want is replaced by the State value an earlier step saved, so a read-back
    can require exactly the value the write chose.

func (e *HTTPEndpoint) MarksExistingRecords() bool
    MarksExistingRecords reports whether the step was built with
    ReadsExistingRecords.

func (e *HTTPEndpoint) OrExisting(status int, text string) *HTTPEndpoint
    OrExisting makes the step an ensure step: a response with status whose body
    contains text means the data the step creates already exists, and the step
    passes without its Contains and SaveJSON checks. Use it for setup steps that
    create a test identity or fixture, which must pass on a fresh application
    and on one that already has the data.

func (e *HTTPEndpoint) ReadsExistingRecords(path string, field string, pattern string) *HTTPEndpoint
    ReadsExistingRecords marks the step as one that reads records users made
    or the deployment seeded, which the probe never wrote: the JSON array
    at dotted path ("" for the whole body) lists them, and field ("" for the
    element itself) is the member value, which must match the RE2 pattern for
    every member. An empty array passes, because a fresh install has no user
    data and is healthy; the engine records whether the step ever saw a record
    the probe did not create (Sample.ExistingRecords). Unlike Each, emptiness is
    not a failure. The step must not template a key a write step of the scenario
    saved.

func (e *HTTPEndpoint) SaveCookie(name string, key string) *HTTPEndpoint
    SaveCookie stores the value of the response's Set-Cookie named name in State
    under key; a response without it fails. Use it on a login step of a test
    identity the scenario created, and send the session with WithHeader.

func (e *HTTPEndpoint) SaveJSON(path string, key string) *HTTPEndpoint
    SaveJSON stores the JSON field at dotted path (for example "id" or
    "data.id") of the response in State under key; a missing field fails.

func (e *HTTPEndpoint) Status(codes ...int) *HTTPEndpoint
    Status replaces the accepted statuses; by default any 2xx is accepted.

func (e *HTTPEndpoint) WithBasicAuth(user string, password string) *HTTPEndpoint
    WithBasicAuth sends HTTP basic authentication. Each {key} in user and
    password is filled from State, for example a probe user's password put there
    ("{password}").

func (e *HTTPEndpoint) WithForm(form Params) *HTTPEndpoint
    WithForm adds a URL-encoded form body.

func (e *HTTPEndpoint) WithHeader(name string, value string) *HTTPEndpoint
    WithHeader sets a request header. Each {key} in value is replaced by
    the State value an earlier step saved, for example a session cookie
    ("session={session}") a login step stored with SaveCookie.

func (e *HTTPEndpoint) WithJSON(template string, params Params) *HTTPEndpoint
    WithJSON adds a JSON body, for the many write APIs that take one. template
    is the JSON document; each {key} in it is replaced by the generated value of
    params[key] or, failing that, the State value an earlier step saved, escaped
    for a JSON string. Write "{key}" for a string and {key} for a number.
    The filled body must be valid JSON.

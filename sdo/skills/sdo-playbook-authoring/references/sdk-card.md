# Program SDK card

GENERATED by scripts/gen_skill_references.sh from Go doc comments in sdo/operator/sdk; do not edit by hand.

Exact signatures programs use, grouped by the fault they repair. Imports: `sdo.dev/operator/sdk`,
`sdo.dev/operator/sdk/program`. Refs are `sdk.ObjectRef{APIVersion, Kind, Namespace, Name}` from bindings
or reads. The full [program SDK](program-sdk.md) is rarely needed.

## Program shape

- `type ProgramSpec struct{ID string; Params []ParamSpec}`: names a playbook program (its directory ID) and declares the roles and values a finding or the responder binds; Diagnose and Mitigate must return identical specs.
- `type ParamSpec struct{Name string; Kind Kind; Required bool; ValueKind ValueKind; Default any}`: declares roles bound by triggering detector findings; Diagnose reads additional objects through ReadView by name or relation, never role enumeration.
- `type Bindings struct{Objects ObjectBindings; Values map[string]any}`: contains object identities and separately typed scalar parameters.
- `func (b Bindings) Parameter(spec ProgramSpec, name string) (any, error)`: resolves one declared value, including a validated default.
- `type Verdict struct{Result Result; Evidence []Evidence; Question string}`: is what Diagnose returns; NeedsJudgement requires a Question.
- `type Result string (Match, NoMatch, Unknown, NeedsJudgement)`: is a diagnosis verdict: Match means the fault is present, NoMatch absent, Unknown that evidence is unavailable.
- `type Evidence struct{Resource sdk.ObjectRef; Fact string; Observed string; Expected string}`: is one observed fact supporting a verdict.
- `type Plan struct{Actions []Action; Rationale string}`: is what Mitigate returns: actions applied in order as one batch.

## Values for writes

- `func FromSource(ref sdk.ObjectRef, path string) Value`: is the field value in the incident's accepted source manifest.
- `func FromObserved(ref sdk.ObjectRef, path string) Value`: is the field value in this invocation's ReadView snapshot.
- `func FromParam(name string) Value`: is a declared scalar parameter's bound value or default.
- `type ValueKind string (StringValue, IntValue, QuantityValue, DurationValue, BoolValue)`: is the schema of a declared scalar value parameter.

## Reads (ReadView)

- `type ReadView interface: WebhookCAMatchesSecret, AdmissionWebhooksFor, ObjectReader, DetectionContext, ScopedObservationSource, ObservationClock, StatefulSets, HorizontalPodAutoscalers, PodDisruptionBudgets, metrics.Source, metrics.AlertSource, metrics.QuerySource, traffic.Source, servicehealth.ReachabilitySource, Logs, LogsWithOptions, metrics.UsageSource, ProbeTCP, ProbeHTTP, DiffAgainstSource, DiffAgainstBaseline, DatabaseUsers, Observe, KubernetesRead`: is a program's frozen, recorded read access to the incident namespace; every read is replayed from the corpus at check time.
- `type DetectionContext interface: DiffAgainstSource(ref ObjectRef) (SourceDiff, error); PodAdmission() (PodAdmissionResult, bool); Namespace() string; ConfigMaps() []corev1.ConfigMap; Services() []corev1.Service; Pods() []corev1.Pod; Deployments() []appsv1.Deployment; ReplicaSets() []appsv1.ReplicaSet; Endpoints() []corev1.Endpoints; EndpointSlices() []discoveryv1.EndpointSlice; NetworkPolicies() []networkingv1.NetworkPolicy; Events() []corev1.Event; ReadyEndpointCountForService(namespace string, service string) int; PodsForService(namespace string, service string) []corev1.Pod; RecentEventsFor(namespace string, kind string, name string) []corev1.Event`: is the frozen snapshot read by detectors and, through ReadView, by programs.
- `ObjectReader.Object(ObjectRef) (*unstructured.Unstructured, error)`: reads one exact object by kind, namespace and name.
- `ReadView.LogsWithOptions(pod sdk.ObjectRef, options corev1.PodLogOptions) (string, error)`: reads bounded container logs; Previous selects the last terminated instance.

## Source drift: a field, ConfigMap entry or object differs from accepted source

- `DetectionContext.DiffAgainstSource(ref ObjectRef) (SourceDiff, error)`: compares a captured resource with accepted source, including source absence.
- `type SourceDiff struct{SourceAbsent bool; Changed bool; Text string}`: is the read-only comparison with the accepted source for one resource.
- `func (d SourceDiff) PresentButNotInSource() bool`: is true while the object exists live but not in accepted source.
- `type SetField struct{Ref sdk.ObjectRef; Path string; Value Value; Reason string; DocumentFormat string; DocumentPath []string}`: writes one schema-checked field (or one ConfigMap JSON/YAML entry) from a Value: accepted source, an observation or a declared parameter.
- `type ReconcileFromSource struct{ Ref sdk.ObjectRef }`: restores a whole source-owned object to accepted source, removing additions SourceDiff reports; prefer SetField for one field.
- `type CreateFromSource struct{Ref sdk.ObjectRef; Reason string}`: restores a missing named object from accepted source.
- `type DeleteObject struct{Ref sdk.ObjectRef; Reason string}`: irreversibly deletes a named object in the incident namespace.
- `type PatchObject struct{Ref sdk.ObjectRef; Type string; Patch json.RawMessage; Edits []ListEdit; Reason string}`: patches any nonsecret Kubernetes object.
- `type Rollback struct{Ref sdk.ObjectRef; ToRevision string}`: restores a workload's fields from an explicit earlier revision.

## Admission webhook CA or policy blocks Pod creation

- `DetectionContext.PodAdmission() (PodAdmissionResult, bool)`: returns the frozen dry-run result, false when unobserved.
- `ReadView.AdmissionWebhooksFor(subject sdk.ObjectRef) ([]AdmissionWebhook, error)`: lists the webhook entries that admit Pod creation for a Namespace or workload; cluster webhook names need no observation grant.
- `type AdmissionWebhook struct{Configuration sdk.ObjectRef; Webhook string; FailurePolicy string; Service *sdk.ObjectRef; Port int32; ReadyEndpoints int; ServingSecrets []WebhookSecretKey; CABundle string}`: is one webhook entry that admits Pod creation in the asked namespace, with its backend: the Service, its ready endpoint count and the Secrets its Pods mount.
- `type WebhookCA struct{Ref sdk.ObjectRef; Webhook string; SecretNamespace string; SecretName string; SecretKey string}`: identifies one webhook and a Secret key.
- `ReadView.WebhookCAMatchesSecret(WebhookCA) (bool, error)`: reports whether one webhook's caBundle equals a Secret key without exposing either value.
- `type SyncWebhookCA struct{Target WebhookCA; Reason string}`: copies one Secret key into the named webhook's caBundle inside the runtime.

## Rollout stuck, Pods unready or crashing

- `func StalledRolloutRelease(view RolloutView, deployment sdk.ObjectRef) []Action`: returns the standard release of a Deployment rollout whose replacement cannot get the place the old revision holds: a current-revision Pod is Unschedulable, or its ReplicaSet cannot create Pods because the namespace quota is exceeded.
- `type RetireOldRevision struct{Ref sdk.ObjectRef}`: scales one old-revision ReplicaSet of a Deployment to zero.
- `type RestartRollout struct{Ref sdk.ObjectRef; Reason string}`: restarts a Deployment's Pods like kubectl rollout restart; Ref must be an apps/v1 Deployment.
- `type DeletePod struct{ Ref sdk.ObjectRef }`: removes one named pod with UID/version preconditions.
- `type ScaleWorkload struct{Ref sdk.ObjectRef; Replicas Value}`: restores replicas from accepted source, observations or a parameter.
- `type WaitFor struct{Ref sdk.ObjectRef; Path string; Equals any; Timeout time.Duration; Interval time.Duration}`: observes a JSON pointer until it equals Equals.

## Service routing and ports

- `ReadView.ProbeTCP(to sdk.ObjectRef, port int32) (ProbeResult, error)`: connects to one port of a Pod or Service and records whether it accepted.
- `ReadView.ProbeHTTP(to sdk.ObjectRef, req HTTPProbe) (ProbeResult, error)`: sends one recorded HTTP request to a Pod or Service.
- `type HTTPProbe struct{Method string; Path string; Headers map[string]string}`: is the request ProbeHTTP sends.
- `type RemoveServicePort struct{Ref sdk.ObjectRef; Name string; Port int32; Protocol string; AllowEmpty bool; Reason string}`: removes exactly one Service port.

## Database users

- `ReadView.DatabaseUsers(DatabaseTarget) ([]DatabaseUser, error)`: lists nonsecret user names and direct roles of one database catalog.
- `type DatabaseTarget struct{Engine string; Pod sdk.ObjectRef; Container string; Database string; Auth *DatabaseAuth; Shell string}`: selects one MongoDB catalog on a named application Pod.
- `type DatabaseAuth struct{Database string; Username CredentialRef; Password CredentialRef}`: authenticates catalog access inside the selected container.
- `type CredentialRef struct{Env string; ConfigMap *ConfigMapCredentialRef}`: selects exactly one reference kind.
- `type ConfigMapCredentialRef struct{Name string; Key string; Assignment string}`: selects a key in the target Pod namespace.
- `type DatabaseRole struct{Database string; Name string}`: is one directly granted role in a named database.
- `type EnsureDatabaseUser struct{Target DatabaseTarget; User string; Roles []DatabaseRole; Password CredentialRef; Reason string}`: creates a missing user or restores its exact direct roles.

## Any other hand repair: commands, HTTP, Jobs, raw API objects

- `type RunScript struct{Script string; Env map[string]Value; Timeout time.Duration; Reason string}`: is a first-class learnable mitigation.
- `type Exec struct{Pod sdk.ObjectRef; Container string; Command []Value}`: executes a provenance-derived command.
- `type EnsureExec struct{Observe Command; Ensure Command; Expect int32; Reason string}`: runs Observe in a Pod and, unless it already exits with Expect, runs Ensure and observes again; effects are irreversible.
- `type EnsureHTTP struct{Observe HTTPRequest; Ensure HTTPRequest; Expect int32; Reason string}`: sends Observe and, unless it already returns Expect, sends Ensure and observes again; effects are irreversible.
- `type RunJob struct{Object ApplyObject; Completion WaitFor}`: creates a named Job or Pod and waits for its actual completion.
- `type ApplyObject struct{Ref sdk.ObjectRef; Object map[string]any; Mode string; Reason string}`: creates a missing object or merges desired fields into an existing object.
- `type KubernetesRequest struct{Ref sdk.ObjectRef; Method string; Path string; Query map[string]string; ContentType string; Body []byte; Reason string}`: exposes the Kubernetes HTTP API, including subresources, cluster resources and discovered kinds.

## Corpus receipt links

- `type ScriptOriginReceipt struct{ScriptDigest string; ID string; IncidentID string; Success bool; StartedAt time.Time; CompletedAt time.Time; Resources []sdk.ObjectRef}`: is protected historical evidence: the original successful repair a learned step encodes.
- `func ScriptDigest(script string) string`: identifies exact script bytes; application inputs belong in Env.

func ApplyRemoveServicePort(object map[string]any, a RemoveServicePort) error
    ApplyRemoveServicePort projects a removal without changing any unrelated
    field. Missing or ambiguous matches and a protected final port leave object

func ApplySetField(object map[string]any, path string, value any) error

    except a missing final env[name=NAME] can insert an entry with that same
    name.

    checks.

func BoundedLogOptions(options corev1.PodLogOptions) (corev1.PodLogOptions, error)
    BoundedLogOptions copies upstream options and enforces finite reads of at
    most 64 KiB.

func CheckReads(view ReadView) (sdk.DetectionContext, func() error)
    CheckReads gives one evaluation its own failure tracking. A failed read
    cannot be ignored to turn Unknown into clearance.

func CheckReplicaSetScales(plan Plan, view ReplicaSetOwnerView, bindings Bindings) error
    CheckReplicaSetScales allows a program to scale a ReplicaSet only when the
    observed ReplicaSet is controlled by a Deployment the program is bound to
    and is not that Deployment's current revision. Retiring an old revision
    is the only repair a program needs on a ReplicaSet; anything else risks an
    outage.

func DocumentWriteRef(action Action) (sdk.ObjectRef, bool)
    DocumentWriteRef identifies actions that project edits onto an existing
    object. Their relative order within that object is preserved in its single
    API write.

func ExpandedSetField(f SetField) bool
    ExpandedSetField reports whether an action uses the structured vocabulary.

func FieldValue(object map[string]any, path string) (any, error)
    FieldValue resolves numeric indexes, unique [name=NAME] list identities and
    bracketed ConfigMap keys. It does not invent missing intermediate objects.

func Kubernetes(view ReadView, sourceBindings ...Bindings) (*kubeclient.ReadClient, error)

    view. Build it once per Diagnose/mitigation or detector invocation.

    and phase replay. Built-in fields retain Kubernetes types; Dynamic and
    RESTMapper cover CRDs. Optional bindings require each role to remain in
    accepted source. Omit them for observations of intentionally source-absent

func ProjectPatch(object map[string]any, a PatchObject) (map[string]any, error)

    Errors leave the input untouched. The API server still validates its schema.

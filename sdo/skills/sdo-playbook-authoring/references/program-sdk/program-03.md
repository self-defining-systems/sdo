type EnsureExec struct {
	Observe Command
	Ensure  Command
	Expect  int32
	Reason  string
}
    EnsureExec runs Observe in a Pod and, unless it already exits with Expect,
    runs Ensure. Observe is a read-only check with three answers: Expect when
    the state holds, the needs-change code (ObservationNeedsChange) when Ensure
    should run, and any other exit when the check itself failed; then Ensure
    never runs and the action fails with that exit code, because a failed check
    is no evidence a write is needed. A successful Ensure is not observed again:
    the post-apply diagnosis and the alerts verify the state. Effects are
    irreversible.

	Reason  string
}
    EnsureHTTP sends Observe and, unless it already returns Expect, sends Ensure
    and does not observe again. As for EnsureExec, only the needs-change code
    (ObservationNeedsChange) leads to Ensure. Effects are irreversible.

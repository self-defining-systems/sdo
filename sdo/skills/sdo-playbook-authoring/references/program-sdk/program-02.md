func BindFinding(spec ProgramSpec, finding sdk.Finding) (Bindings, error)
    BindFinding binds one finding without enumerating objects or assignments.
    Explicit ParameterBindings take precedence; otherwise only a unique resource
    of the declared kind in the finding can bind a role. Additional objects are
    read by Diagnose through ReadView, by name or relation.

    Named bindings are the finding detector's claim about what its own playbooks
    repair, so they bind only programs the finding lists by logical ID (the
    Finding.Playbooks contract; the controller rejects any other reference).
    A finding that lists no playbook (drift and source-inventory findings)
    offers them to every program; the memory check refuses an incident detector
    that sets named bindings without declaring its playbooks.

type DataEffect string
    DataEffect classifies what an action may do to the records of a store.
    Go assigns it from what it can see of the action; an author's word never
    lowers it, so anything opaque is EffectUnknown.

const (
	// EffectRead changes nothing.
	EffectRead DataEffect = "read"
	// EffectDerivedInvalidate drops entries of a component that only holds
	// copies of another component's data (a cache that refills).
	EffectDerivedInvalidate DataEffect = "derived-invalidate"
	// EffectStoreSetting changes a store's runtime setting or catalog item
	// (an account, a role, a flag), not its records.
	EffectStoreSetting DataEffect = "store-setting"
	// EffectDataWrite changes records.
	EffectDataWrite DataEffect = "data-write"
	// EffectUnknown is the default for anything opaque: it may do any of the above.
	EffectUnknown DataEffect = "unknown"
)

type DataScope = storeops.Scope
    DataScope selects records with an engine-native, read-only selector:
    for redis a database number and key glob, for mongodb a database, collection
    and JSON filter, for postgres or mysql a database, table and WHERE body,
    for memcached a key glob (keys listed with lru_crawler metadump). Limit
    bounds the items (0 is 10000, at most 100000); a larger scope is refused.

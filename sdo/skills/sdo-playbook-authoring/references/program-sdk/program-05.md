type StoreBackup struct {
	ID     string
	Target StoreTarget
	Scope  DataScope
	Reason string
}
    StoreBackup copies a scope's records. They go to backup storage. The storage
    is outside .sdo/, on the controller's repository volume, per incident.
    It records its ID, item count, size, SHA-256 and the store's facts at
    backup time. It changes nothing in the store (effect read) and fails when
    the scope holds more than its limit or the dump exceeds the size cap.
    ID names the backup within the incident; it is immutable. A redis backup
    holds DUMP-serialized keys, a mongodb one canonical Extended JSON documents,
    a postgres one COPY rows.

    environment.

type RetireOldRevision struct {
	Ref sdk.ObjectRef
}
    RetireOldRevision scales one old-revision ReplicaSet of a Deployment to
    zero. It releases a rollout whose replacement Pod cannot be placed or
    created while the old revision's Pod holds its place (hard anti-affinity,
    a host port, node capacity or namespace quota). The Deployment controller
    never scales a retired revision back up. It is refused like any ReplicaSet
    scale for a current revision or a ReplicaSet without an observed controlling
    Deployment.

    FailedCreate. It changes only a controller annotation, preserving replicas

    namespace and checks live failure evidence before writing. A retry is not
    proof of admission or application recovery; independent verification remains
    required. Webhook repairs automatically include retries for affected sets.

type StoreBackup struct {
	ID     string
	Target StoreTarget
	Scope  DataScope
	Reason string
}
    StoreBackup copies a scope's records to backup storage. The storage is
    outside .sdo/, on the controller's repository volume, per incident.
    It records its ID, item count, size, SHA-256 and the store's facts at
    backup time. It changes nothing in the store (effect read) and fails when
    the scope holds more than its limit or the dump exceeds the size cap.
    ID names the backup within the incident; it is immutable. A redis backup
    holds DUMP-serialized keys, a mongodb one canonical Extended JSON documents,
    a postgres one COPY rows.

func (a StoreBackup) Validate() error

type ReconcileFromSource struct{ Ref sdk.ObjectRef }
    ReconcileFromSource restores a whole source-owned object to accepted source,
    removing additions SourceDiff reports; prefer SetField for one field.
    For a Secret the controller writes the literal data of the accepted render
    (the keys the source declares; other keys stay) and nothing records a value:
    the receipt names the keys. It refuses a Secret whose source has no
    literal data or whose render is not deterministic (a generated password);
    then Escalate. Restart the readers that started after the foreign change
    with RestartRollout later in the same plan, because a running Pod keeps the
    value it started with (finding secret-readers-predate-change names them).

type RepairData struct {
	Target          StoreTarget
	Scope           DataScope
	Statement       string
	MemberPredicate *MemberPredicate
	CopyFrom        *DataScope
	ExpectMin       int
	ExpectMax       int
	Backup          string
	Reason          string
}
    RepairData runs one write on a scope. Its effect is data-write. It sets
    exactly one of:
      - Statement: a redis single-key write per matched key ("SREM member"),
        a mongodb update document or pipeline, a postgres or mysql SET clause,
        or "delete" (the only memcached statement);
      - MemberPredicate (redis): remove the members it selects from every set,
        sorted set or list the scope matches, for example the members that are
        not digits or whose "post:{member}" key is missing;
      - CopyFrom: copy every item of the CopyFrom scope that Scope's namespace
        lacks into it (a renamed collection, table or key pattern back under its
        name; redis merges sets and sorted sets member by member). Scope names
        the target namespace whole; CopyFrom is left as it is.

    The controller counts the matching items first (the CopyFrom items for a
    copy) and refuses unless the count is within [ExpectMin, ExpectMax], writes
    (atomically with the count on redis, postgres and mysql), then counts Scope
    again and reads the store's facts. Backup optionally names a StoreBackup of
    this incident; the controller records it and whether it covers Scope.

func (a RepairData) Validate() error

type RestartRollout struct {
	Ref    sdk.ObjectRef
	Reason string
}
    RestartRollout restarts a workload's Pods like kubectl rollout restart. It
    stamps the Pod template's kubectl.kubernetes.io/restartedAt annotation, and
    the workload's own update strategy replaces the Pods. Pods the controller
    will not replace (an OnDelete strategy, or an OrderedReady StatefulSet
    waiting on an unready Pod) are deleted so they restart too; the receipt
    names each deleted Pod and why. Ref must be one named apps/v1 Deployment,
    StatefulSet or DaemonSet.

type InvalidateDerived struct {
	Target StoreTarget
	Scope  DataScope
	Reason string
}
    InvalidateDerived drops a derived cache's entries. They refill from source.
    Its effect is derived-invalidate on Scope when the accepted application
    map marks the component data.role derived, and data-write otherwise.
    The controller records the derivation it ran under: whether the map marks
    the component derived and whether each derived_from source passed its live
    store-state checks. Flushing a cache whose source is damaged refills it with
    the damage. Redis and memcached support it; postgres, mysql and mongodb
    refuse.

	Source string `json:"source"`

	// health probes sign in as: it makes sure a non-admin user named by its

	// procedure of a map is the probe identity.

    Procedure is one operations procedure the application itself ships:
    a self-check, a repair task, a data task or a long job, recorded under
    `procedures` in the accepted application map. It runs either in a
    component's workload (Component, Container, Command) or by re-creating
    a Job of the accepted source (Job). Command arguments may hold {{name}}
    placeholders for declared parameters.

func (p Procedure) Bind(values map[string]any) ([]string, error)
    Bind validates values against the declared parameters and returns the
    command with every placeholder replaced. A missing value takes the
    parameter's default; a required parameter without one is an error, and an
    optional one without a default is an error only when the command uses it.

func (p Procedure) Validate() error

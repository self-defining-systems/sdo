# Responder command reference

GENERATED by `uv run python -m sdo.agents.responder.command_reference` from the CLI parser, its response definitions and the generated command-report schema. Do not edit by hand.

## Output

Use `--json` before or after the command. Read commands return the complete JSON response; their default text points to a complete JSON file. Mutations return a compact JSON envelope with `command`, `summary`, `details_file`, `incident_verified` and conditional `error`/`failure_reason`. The envelope is limited to 2048 UTF-8 bytes; query `details_file` for complete evidence. The worker provides `jq` for JSON extraction.

Response keys below are conditional: absence is not success or health. Ordinary responses share `command`, `summary`, `healthy`, optional `error` and optional `incident_verified.{verified_at,message}`. Only independent verification establishes recovery. A pending detector reason is unproven health. Closed-incident reads/reports remain available; new mutations are rejected.

Mutation files contain these generated top-level arrays:

- `actions[]`: {command,summary,program_runs,report,option_reports}: complete independent option outputs/receipts; overlapping writes refused
- `findings[]`: {summary,status,detector_id,fingerprint,primary_resource,evidence}: current findings with full evidence
- `fixed[]`: Finding (findings[] shape): absent since the before snapshot
- `new[]`: Finding (findings[] shape): new fingerprint or changed evidence; possible regression
- `option_reports[]`: {status,rounds,attempt_id}: typed per-option execution reports in selection order
- `unchanged[]`: Finding (findings[] shape): same fingerprint and evidence

## mitigate

apply several independent options in one call; overlapping options refused; show progress and full JSON

```text
sdo mitigate [-h] [--finding FINGERPRINT] [--rounds ROUNDS] [--selection FILE] [--selection-set FILE] [--option ID] [--param NAME=VALUE] [option]
```

Apply several independent options in one call; overlapping object write sets are refused before writes. Advertised option IDs remain valid for this session across filtered menu calls. Learned program preconditions are rechecked against live state before any batch writes. Use repeated --option ID followed by that option's --param NAME=VALUE, or --selection-set FILE with version 1 and options [{option_id, bindings, parameters, finding_fingerprints}]. Each option has its own receipt; one call uses one round. Pending rollout returns its application ID and read-only tools remain available. A single option also accepts --NAME VALUE parameters. Uses the ordinary executor and controller RBAC; up to five rounds per incident. A script fix is a first-class learnable mitigation with relation-derived Values, within incident budgets. Program commands use the current checkout, including shared libraries and new playbook IDs. Edits compile on demand; fix compile errors in place and retry. Revision receipts use working-tree:<source digest> for unpublished code. Reusable API reads use program.Kubernetes(view) with upstream client-go options; reads are recorded for replay.

- `option`: advertised option ID or unambiguous program ID
- `--finding`: target finding fingerprint; repeat for each intended finding
- `--rounds`: maximum rounds within the remaining incident allowance
- `--selection-set`: version 1 selection set with per-option bindings and parameters
- `--option`: independent option ID; repeat, with per-option --param arguments

```text
Parameters accept ordinary JSON objects, arrays, numbers and booleans, as well as strings. sdo menu exports recursive parameters[].schema for every option, plus selection_schema and selection_set_schema; nested properties, required fields and oneOf choices describe accepted shapes. parameters[].example supplies typed synthetic inputs; replace names/values using incident evidence. CLI --param NAME=VALUE accepts JSON text for structured values. EnsureDatabaseUser repairs a MongoDB user in one call. Its password and target.auth username/password take exactly one credential reference: {env: NAME} or {config_map: {name: CONFIGMAP, key: KEY, assignment: optional_NAME}} in the target Pod namespace. Assignment selects one literal NAME=value line. The executor resolves values privately; never put credential values in arguments, evidence or memory. Direct Secret keys are unavailable.
```

Complete report fields (`details_file`): `actions[].{application_id, targeted_healthy, mitigation_health, rollout_pending, program_revisions}, option_reports[]`.

## act

record a live mutation; show progress and a complete JSON report

```text
sdo act [-h] --resource Kind/namespace/name [--summary SUMMARY] [--irreversible] ...
```

Run one live mutation and record its repair receipt (target, resources, timing, outcome and command line). The command's exit code is returned. Do not hand-write receipts.

- `--resource`: object the command mutates (Kind/name when cluster-scoped); repeat for each one
- `--summary`: one line describing the repair
- `--irreversible`: the mutation cannot be undone
- `act_command`: the mutating command

```text
Example: sdo act --resource Deployment/app/api -- kubectl -n app set image deployment/api api=img:1.2
```

Complete report fields (`details_file`): `actions[].{success, exit_code, receipt, output, failure_reason}`.

## verify

read cached controller verification; optionally await a stable verdict

```text
sdo verify [-h] [--wait SECONDS]
```

Reads the controller's cached health and inventory verdict immediately. Pending observation windows, including unproven synthetic scenarios, are not healthy. Wait on SDO's verification instead of sleeping. After closure, incident_verified is an informational warning on every response; reads and reports remain available, while mutations are rejected. After verified closure, report grace and outcome/reflection work continue during maintenance pauses.

- `--wait`: wait for stable verification, a new/reactivated finding, or this timeout (0: cached and instant)

Key JSON fields: `healthy, unresolved, findings[], detector_states[], drift_events[]`.

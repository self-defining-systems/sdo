var (
	// ErrUnavailable marks a read that could not observe the state.
	ErrUnavailable = errors.New("read unavailable")
	// ErrReadReplyLimit is an unavailable observation whose reply exceeded the host frame budget.
	ErrReadReplyLimit = Classified("program read result exceeds the memory-host message limit", ErrUnavailable)
	// ErrRefused marks a read the target itself answered with a refusal.
	ErrRefused = errors.New("read refused by target")
	// ErrInvalidRead marks a read the program was not allowed to make.
	ErrInvalidRead = errors.New("invalid read")
)
    A read answers one of four things, and a live view, the memory host and a
    replay give the same answer for the same world:

      - observed: SDO saw the state, including "it is not there" (an absent
        object is a value, see ErrObjectAbsent); a program may reason on it.
      - refused: the target answered and said no (a database login was
        rejected); a program may reason on it and try something else.
      - unavailable: SDO could not observe (no client, kind not captured,
        timeout, no accepted source); a program may only treat it as "I do not
        know".
      - invalid: the program asked something illegal (a Secret read, a ref
        outside the namespace, the read budget); a program bug.

    An error that carries no class is unavailable: fail closed.

var ErrNoFieldComparison = errors.New("diff holds no accepted/observed field comparison")
    ErrNoFieldComparison means a diff holds no accepted/observed field
    comparison, such as a baseline diff or a diff read from an unavailable
    source.

var ErrObjectAbsent = errors.New("object is absent from snapshot")
    ErrObjectAbsent means the object was observed to be missing: the API
    answered NotFound, or the snapshot holds a complete list of the object's
    kind without it. Absence is an observation a program may reason on.

var ErrObjectNotCaptured = Classified("object not captured", ErrUnavailable)
    ErrObjectNotCaptured means the snapshot cannot say whether the object
    exists: its kind was not listed completely. It is a gap in evidence,
    never an absence.

var ErrScopedObjectAbsent = fmt.Errorf("%w", ErrObjectAbsent)
    ErrScopedObjectAbsent reports a declared, observed scoped target that does
    not contain the named object.

    sentinel of class, so a replayed failure classifies exactly as it did live.
    An unknown or empty class is a legacy recording and reads as unavailable,
    except the SDK's own absent message, which was always an observation.

    active findings of one detector with the same fingerprint are one finding.

    hold the open incident (its opening and joined alerts); empty when no
    incident is open or the context carries none.

func HeldPastSelfHeal(ctx DetectionContext, since time.Time) bool
    HeldPastSelfHeal reports whether a condition that has held since since
    outlived Kubernetes' own self-healing: at least the context's self-heal
    hold passed by its observation time. since is a Kubernetes timestamp (a
    condition's lastTransitionTime, an object's creation); an unknown since or
    observation time never proves the hold elapsed.

func IsSDOFieldManager(manager string) bool
    IsSDOFieldManager reports whether manager is one of SDO's own.

func ObservationTime(ctx DetectionContext) time.Time
    ObservationTime returns the time a detection context describes. Detectors
    that judge an age ("Pending longer than a minute", "restarted within five
    minutes") must use it instead of time.Now, so Detect stays a pure function
    of its snapshot and replays identically.

    A context without a recorded clock falls back to the latest timestamp
    recorded in its Pods, Deployments, ReplicaSets, and Events. That is a
    deterministic lower bound on the real observation time, so an age derived
    from it can only be underestimated: a grace period may elapse late, never
    early. It is zero when the context records no time at all.

func PodStarting(ctx DetectionContext, pod corev1.Pod) bool
    PodStarting reports whether a pod that is not yet ready is still inside
    its startup: a running unready container within its startup allowance,
    or a pod whose containers have not started yet within the self-heal hold of
    its creation (image pull, scheduling, init containers).

func PodWorkload(ctx DetectionContext, pod corev1.Pod) string
    PodWorkload names the workload a pod belongs to as "Kind/name": its
    controlling owner, or, for a ReplicaSet, the Deployment that owns that.
    A pod without a controlling owner is its own workload ("Pod/name").

func Predicted(finding Finding) bool
    Predicted reports whether the finding is a forecast (MetadataPredicted).

    ProjectCABundle replaces certificate bytes with an idempotent digest.
    It is shared by typed observations, raw API reads and capture projection.

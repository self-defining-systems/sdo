type ObservedStartupSource interface {
	// ObservedStartup is the workload's ("Kind/name", see PodWorkload)
	// observed startup allowance; zero when none was observed.
	ObservedStartup(workload string) time.Duration
	// ObservedStartups lists every workload's allowance, for snapshot capture
	// and the memory-host wire.
	ObservedStartups() map[string]time.Duration
}
    ObservedStartupSource is implemented by detection contexts that carry how
    long each workload's pods took to become Ready on their recent healthy
    starts, as an allowance (a high percentile plus a margin, from the
    controller). Snapshot capture records it, so replay judges a starting pod
    exactly as the controller did.

type PersistencePolicy struct {
	Firing   int
	Clearing int
	// MinDuration, when positive, additionally requires a finding to have
	// been continuously observed for at least this long before it fires.
	// A finding that reaches Firing evaluations sooner stays pending until
	// MinDuration also elapses, then activates on its next observation. Zero
	// keeps the evaluation-count-only policy. This absorbs findings whose
	// evaluation count crosses the firing threshold within one brief stall
	// (for example a synthetic-traffic window re-evaluated on every poll),
	// while a persistent fault still fires once both conditions hold.
	MinDuration time.Duration
}

    holds it, so Mutations shows what admission changes in a Pod the workload

type SourceDiff struct {
	// SourceAbsent is true only after a successful accepted-source lookup finds no object.
	SourceAbsent bool `json:"source_absent,omitempty"`
	// LiveAbsent is true when the object was observed to be missing live (the
	// API answered NotFound, or a complete list of its kind lacks it). It is
	// an observation, never an error. With SourceAbsent false the object is
	// declared but missing (MissingButInSource).
	LiveAbsent bool `json:"live_absent,omitempty"`
	// Changed reports declared fields that differ and fields that source does
	// not declare and that were absent when SDO accepted (adopted) the object.
	// Server defaults, fields present at acceptance and kubernetes.io/k8s.io
	// bookkeeping are not changes; nor is a new value of an undeclared field
	// that existed at acceptance. When declared fields agree but the object
	// has no acceptance record for this source, the diff is an error, not
	// unchanged. ReconcileFromSource removes the additions it reports.
	Changed bool `json:"changed"`
	// Text is human-readable evidence for a verdict or finding. Never match
	// on it: a substring of a whole document cannot tell which field or
	// container changed. Compare fields with Field and ContainerChanges.
	Text string `json:"text,omitempty"`
}
    SourceDiff is the read-only comparison with the accepted source for one
    resource. Missing source or observation evidence is an error, never a clean
    comparison.

func (d SourceDiff) ContainerChanges() ([]ContainerChange, error)
    ContainerChanges compares a workload's or Pod's containers with accepted
    source by kind and name: an added init container is never an app image
    change.

func (d SourceDiff) Field(path string) (FieldValues, error)
    Field compares one field path, such as "spec.replicas", on both sides.
    The path takes the same selectors as the repair actions: "[name=X]" picks
    the one list entry with that name ("containers[name=app]"), "[N]" a list
    index and "[key]" a map entry ("data[config.yaml]"). A selector that matches
    nothing is an absent field; a malformed path is an error, never a silently
    absent field. Compare containers by name with ContainerChanges, never by
    list position.

func (d SourceDiff) MissingButInSource() bool
    MissingButInSource is true while accepted source declares the object and it
    is absent live: a deleted object. It is the mirror of PresentButNotInSource,
    and turns false once CreateFromSource has recreated the object, so a
    recreate-style Diagnose matches on it and the post-plan re-diagnose clears.

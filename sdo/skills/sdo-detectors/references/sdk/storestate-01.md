package storestate // import "sdo.dev/operator/sdk/storestate"

Package storestate reads value-free facts about a data store: whether it accepts
writes and why not, its replication role, its connection and memory caps,
its principals and their grants, its catalog (indexes, validators, locks) and
inventory counts. It never reads records.

An engine Adapter supplies one read command, run inside the store's own
container through the podread path with the store's own CLI, and the parser
of its output. Facts from a healthy moment form a baseline; Diff lists the
items that differ now, so a finding names the exact setting, role or grant that
changed. A read that gives no answer is an error, never a healthy result.

func NewDetector(c Config) (sdk.Detector, error)
    NewDetector returns a deterministic detector of the store's facts.
    It reports a write block, a role, principal or catalog change against
    the baseline, a refusal of its own read, connection or memory use at
    NearLimit of a cap (memory only under a noeviction policy), and a session
    holding a lock others have waited on for LockWaitThreshold. Each finding
    names the component, the Pod and the changed item. A read that gives no
    complete answer is a detector error, never a clear, except a store a
    GapWithoutBaseline reader has never read healthy, which is a coverage gap.

func UsableAsBaseline(id string, result podread.Result) error
    UsableAsBaseline reports why a store-state pod read cannot become the
    healthy reference: a reading that is unavailable, unparsable, refused (other
    than an unsupported command) or shows a write block. A store whose read was
    refused when health was promoted is never observed, so its later refusals
    stay coverage gaps instead of being compared with a refused reference.
    It returns nil for a pod read that is not a store-state read.

type Adapter interface {
	Engine() Engine
	DefaultPort() int
	ReadCommand(Endpoint) []string
	// Parse returns the facts of a complete read. A read that reached no
	// server, or lacks a section, is an error.
	Parse(stdout string) (Facts, error)
}
    Adapter is one engine's read: an argv run in the store's container (its own
    CLI, credentials from the container environment, output never carrying a
    secret or a record) and the parser of its output. The read is one command so
    a store costs one pod read.

func AdapterFor(engine Engine) (Adapter, bool)
    AdapterFor returns the engine's adapter, or false when SDO has no reader for
    the engine yet.

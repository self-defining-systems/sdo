func ReadErrorClass(err error) string
    ReadErrorClass names an error's class: absent, refused, unavailable or
    invalid. A nil error has no class. When an error carries several, the least
    permissive one wins (invalid, then unavailable, then refused, then absent),
    so a program is never given more freedom than its worst read allowed.

	FailurePolicy  string                `json:"failure_policy"`
	TimeoutSeconds int32                 `json:"timeout_seconds,omitempty"`

	Service        *ObjectRef            `json:"service,omitempty"`
	Port           int32                 `json:"port,omitempty"`
	URL            string                `json:"url,omitempty"`
	ReadyEndpoints int                   `json:"ready_endpoints"`
	ServingSecrets []WebhookSecretKey    `json:"serving_secrets,omitempty"`
	CABundle       string                `json:"ca_bundle,omitempty"`
}
    AdmissionWebhook is one webhook entry admitting Pods in the namespace.
    Its backend is the Service, its ready endpoint count and the Secrets its
    Pods mount, or, for a webhook served outside the cluster, the URL's scheme
    and host. CABundle is a digest, never certificate bytes. TimeoutSeconds
    is how long the API server waits for it (DefaultWebhookTimeoutSeconds
    when the entry declares none); ObjectSelector, when set, limits it to Pods
    whose labels match. To repair a broken admission webhook, bind the failing
    Namespace or workload (not the webhook configuration or Secret), read it
    with ReadView.AdmissionWebhooksFor, and repair with SyncWebhookCA for the
    CA, PatchObject for failurePolicy or the service reference, or DeleteObject
    for an orphaned entry.

func ConfigMapKeyReferencesForDeployment(deployment appsv1.Deployment) []ConfigMapKeyReference
    ConfigMapKeyReferencesForDeployment returns explicit keys consumed through
    container/init-container env, ConfigMap volumes, and projected volumes.
    EnvFrom and volumes without Items consume all available keys and therefore
    impose no individual key requirement. Secret references are never returned.
    Results are sorted by name/key; required references win over optional ones.
    This is reference metadata only, not a credential-safety assertion about
    data.

	Name     string `json:"name"`
	Optional bool   `json:"optional"`
}
    ConfigMapReference describes a ConfigMap consumed by a Deployment pod
    template. Optional references do not make an absent ConfigMap a fault.

    ConfigMapReferencesForDeployment returns the distinct ConfigMaps referenced
    by a Deployment's volumes and container environment. Results are sorted by
    name so detector output does not depend on manifest field ordering. If the
    same ConfigMap is referenced as both optional and required, the required
    reference wins.
